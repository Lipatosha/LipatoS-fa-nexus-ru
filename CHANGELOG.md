# История изменений

## 1.1.1

- Исправлена критическая проблема производительности при открытии больших листов D&D5e.
- По профилю Firefox обнаружено, что старый `MutationObserver` русификатора участвовал примерно в 98–99% сэмплов главного потока во время зависания.
- Убрана дорогая проверка `win.querySelector(...)` для каждого текстового/DOM-узла.
- Убрано глобальное `translateSettingsDom(document)` после каждой мутации.
- Области FA Nexus теперь обнаруживаются один раз и помечаются, после чего перевод выполняется только внутри них.
- Обычные окна Foundry и листы персонажей D&D5e теперь игнорируются русификатором.
- Сохранён полный динамический перевод интерфейса FA Nexus.
- Добавлена автоматическая проверка JavaScript/JSON и сборка ZIP через GitHub Actions.

## 1.1.0

- Расширен словарь до полной русификации интерфейса FA Nexus 0.5.3.
- Переведены ранее оставшиеся английскими элементы окна **Asset Placement Options**: `Single`, `Scatter`, `Scatter Eraser`, `Transform`, `Color`, `Hue`, `Saturation`, `Brightness`, `Contrast`, `Spread`, `Enabled`, `Undo`, `Redo`, `Commit` и связанные подсказки.
- Переведены элементы **Path Editor v2 Options**: `Curve`, `Draw`, `Edit Shapes`, `Close Loop`, `Foundry Walls`, `Merge on Commit`, параметры цвета, трансформации и сеанса.
- Добавлен перевод интерфейсов размещения токенов, рисования текстурами, строительства, менеджера слоёв, порталов и связанных подсказок.
- Исправлен перевод заголовков окон Foundry: русификатор теперь распознаёт окно по содержимому FA Nexus, а не только по английскому заголовку.
- Добавлен регистронезависимый перевод для заголовков и секций, написанных заглавными буквами.
- Добавлены динамические шаблоны для высоты, количества объектов/тайлов, выбранной стены и привязки к сетке.
- Внутренний ID `fa-nexus-ru` сохранён, обновление устанавливается поверх версии 1.0.0.

## 1.0.0
- Первая рабочая версия русификатора FA Nexus в линейке **LipatoS**.
- Добавлен русский перевод основных разделов и инструментов FA Nexus.
- Добавлен перевод кнопок, полей поиска, подсказок, параметров и элементов настроек.
- Добавлен динамический перевод элементов интерфейса, создаваемых FA Nexus после загрузки страницы.
- Добавлен перевод реестра настроек FA Nexus и связанных элементов интерфейса Foundry.
- Добавлены CSS-правки для длинных русских подписей.
- Сохранён внутренний ID `fa-nexus-ru` для совместимости с уже установленной версией.
- Модуль оформлен для установки и обновления через GitHub-манифест LipatoS.
